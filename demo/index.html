How to use and read this page

Use it

  1. Pick a design above the layout: the systolic array or the SIMT core.
  2. Hover the layout to identify any cell: its block, its cell type and whether it is on the critical path. On a phone, tap.
  3. Color by block (which PE or lane a cell belongs to) or by kind (flip-flop vs. logic gate).
  4. Toggle overlays: the critical path, routing congestion and the I/O pins on the die edge.
  5. Hover a row in the critical-path table to find that gate on the layout.
  6. Open the Verilog at the bottom to see the source the layout was built from.

Read it

The layout
A top view of the placed chip. The outer box is the die, the inner box the core where cells sit in 1.4 µm rows. Each small rectangle is one standard cell (a gate or flip-flop) from the Nangate45 library.
Critical path
The slowest chain of gates between two flip-flops (or from an input). Its delay sets the fastest clock the block can run at; the red line connects its cells in order.
Congestion
How full the routing tracks are in each 2.8 µm tile. Amber is near capacity; red tiles are over 100%, where wires would have to detour or the layout must spread out.
Slack and fmax
Slack is how much earlier than the clock edge a signal arrives; positive means it makes it. WNS is the worst slack; fmax = 1 / (clock period − WNS).

Try this

  • Structure survives. Color the systolic array by block: its 16 processing elements land as 16 tiles in a rough 4×4 grid, though nothing told the placer about the grid. Wires between neighbors pulled them there.
  • Where GPUs hurt. Turn on congestion for each design. The SIMT core runs 1,388 tiles above 85% of their tracks, against 459 on the systolic array, because its register-file read muxes fan wires in from everywhere. Its first routing attempt overflowed, so the flow inflated the cells in the hot tiles and re-placed them; one round was enough to route cleanly.
  • Follow the slowest path. On the systolic array, the red line stays inside one PE: flip-flop → signed multiplier → adder → accumulator, 29 gates. On SIMT it starts at the instruction input and runs through register-file muxes into the ALU.
  • Count the memory. Color the SIMT core by kind: 1,024 of its 1,088 flip-flops are register-file bits.

Static timing

The critical path, gate by gate

Each row is one gate on the slowest path, in signal order. Gate is the cell's own delay from the Liberty tables (it grows with the load it drives); wire is the delay of the routed wire into it. Arrival is the running total. The last row must arrive before the clock period minus the capture flip-flop's setup time.

Timing margin

Slack at every endpoint

One bar per 50 ps slack band, counting the flip-flop inputs and outputs that land in it. Everything right of zero meets the clock. The leftmost bar holds the critical path; a long tail to the right means most of the block has room to spare and only a few paths need work.
